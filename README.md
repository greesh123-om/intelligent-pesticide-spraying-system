# intelligent-pesticide-spraying-system
Designed a smart agricultural system using computer vision to detect plant infection levels and optimize pesticide spraying. The system identifies infected regions and adjusts pesticide application based on infection severity to reduce chemical usage and improve crop protection.

## Overview
This project presents an intelligent agricultural system that detects plant infections using computer vision and optimizes pesticide spraying based on infection severity.

## Objectives
- Detect plant infections automatically
- Reduce excessive pesticide usage
- Improve crop protection efficiency

## System Workflow
1. Capture crop images using a camera
2. Detect infected plant regions using computer vision
3. Analyze infection severity
4. Adjust pesticide spraying accordingly

- Machine Learning
- Embedded Systems
